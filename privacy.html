一、我们不收集什么

本工具是纯本地离线工具。我们不收集任何可识别你身份的个人信息。

类型是否收集说明
微信账号 / 手机号不收集无需注册、无需登录
位置信息不收集工具不含任何定位功能
通讯录不收集无相关功能
设备标识 / IMEI不收集不读取
使用日志 / 埋点不收集不含任何第三方统计 SDK

二、数据存储

  • 全部句库（13 语种 2340 句）与词库（7 语种 7000 词）随程序打包分发，不联网获取。
  • 你的「当前语种」「解锁状态」等偏好仅保存在本机（网页版 localStorage；小程序版 wx.setStorage）。
  • 这些数据不会上传到任何服务器，也不会同步到其他设备。
  • 清除浏览器数据 / 清除小程序数据即可彻底删除，且无法恢复。

三、语音朗读（TTS）

本工具的朗读不发送你的任何数据到第三方。发音有两种方式：

形态方式数据流向
网页版浏览器原生 SpeechSynthesis（Chrome / Safari / Edge 自带）文本不离开你的设备，完全本地合成
网页版（微信内置浏览器等无语音合成环境）下载开发者预生成的 mp3 音频文件仅下载音频文件，不上传任何数据
微信小程序版微信云开发（CloudBase）云存储下载预生成 mp3仅下载音频文件，不上传任何数据

音频是开发者离线生成后上传的静态内容，与用户无关：同一段句子对所有用户都是同一个 mp3 文件。小程序版使用腾讯科技的微信云开发服务（云存储 + 云调用）承载音频下载。

若你不希望触发任何网络请求，可完全不使用朗读功能——查阅功能在离线状态下完全可用；已缓存的音频在断网时照常发音。

四、第三方服务

本工具不接入广告、不接入统计、不接入任何第三方追踪。除下表的音频分发服务外，运行时不与任何服务器通信。

服务提供方用途数据流向
微信云开发（CloudBase）云存储 / 云调用腾讯科技存放并分发预生成发音音频仅下载音频文件，无上传
GitHub PagesGitHub, Inc.（美国）托管本静态网页与音频仓库常规网页访问日志

各服务由对应提供商按其自身隐私政策处理数据。

五、你的权利

  • 随时清除本地缓存（浏览器：清除站点数据；微信：设置 → 清除小程序数据）
  • 随时卸载小程序或关闭网页，本地数据一并删除
  • 无需注册即可使用全部浏览功能
  • 本工具不收集数据，因此不存在「查询 / 更正 / 删除个人数据」的请求场景——因为我们没有你的个人数据

六、未成年人保护

本工具为通用外语学习工具，未成年人可在监护人陪同下使用。由于不收集任何个人信息，未成年人不涉及个人信息处理风险。

七、协议变更

如有重大变更，会在本页与小程序内显著位置公告。继续使用即视为接受变更后的协议。
